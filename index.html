Data & import

Paste plain-text events below and click Apply. One event per line. Events are matched by date + title: a matching line updates that event, otherwise it is added. The file you Export/Save is your local flat-file database — edit it and paste or load it back in any time.

Accepted text formats & examples

Pipe format (this is exactly what Export/Save produces):

DATE | TIME | TITLE | TOWN | REGION | OBM THEME | DS CATEGORY | STATUS
2026-10-02 | 08:00 | OBM Keynote | Alice Springs | Central | | | Pending

Loose format (like the original program list) also works:

OBM Keynote Alice Springs, 2 Oct, 08:00:am Status: Pending
  • Leave a field blank between pipes to keep the event's existing value.
  • Dates are October 2026; time accepts 8:00am, 17:30, 5:30pm (blank = all day).
  • Status: Pending, Confirmed or Cancelled. Lines starting with # are ignored.
